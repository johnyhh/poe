Attribute Ownership

Manage ownership of attributes. Only one service may own any user attribute at a time. OAuth2 clients must acquire ownership before writing data to attributes.

Enter attribute names or templates, one per line. For acquire: use "template:mood" or "name:mood_note". For release: use "mood_note".

Data Upload

First line: headers (date column + attribute names). Following lines: data rows. Use tab, comma, or space as separators. Date format: YYYY/M/D or YYYY-M-D
