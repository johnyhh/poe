      使用說明 (User Manual)

      年度管理 (Year Management)

      1. 使用頁面頂部的「年份」選擇器來選擇要查看的年份。

      2. 點擊「New Year」按鈕創建新的年度:

      • 設置新年度的初始年假和恩恤假餘額
      • 選擇是否結轉上一年未使用的假期餘額

      假期餘額 (Leave Balance)

      1. 設置初始年假及恩恤假餘額

      2. 查看所有假期類型的餘額摘要:

      • 已使用的假期日數
      • 已計劃但未使用的假期日數
      • 淨餘額及預計餘額
      • 病假及無薪假的統計

      假期申請 (Leave Application)

      1. 填寫表格申請新假期:

      • 選擇開始日期，假期類型，和時長
      • 如選擇「多日」，需設置結束日期
      • 填寫假期原因（可選）
      • 選擇當前狀態

      2. 管理現有的假期申請:

      • 使用勾選框按類型和狀態篩選假期申請
      • 編輯或刪除現有申請
      • 直接在表格中更改假期狀態

      狀態工流程 (Status Workflow)

      1. 添加、刪除或重新排序狀態步驟

      2. 為每個狀態設置顏色

      3. 添加公眾假期以在計算假期日數時跳過

      電子郵件模板 (Email Template)

      1. 設置年份，月份範圍和截止日期

      2. 選擇要包含的假期狀態

      3. 生成格式化的電子郵件模板

      4. 自定義狀態顯示映射，衝突列表和備份計劃

      5. 將模板複製到剪貼板以便貼入電子郵件

      導入/導出 (Import/Export)

      1. 導出所有數據為 JSON 文件以備份

      2. 從 JSON 文件中導入數據以恢復設置

      3. 一鍵複製配置字串：將所有配置壓縮成 Base64 字串

      • 點擊「複製配置字串」按鈕複製到剪貼簿
      • 可存在任何地方（筆記本、剪貼簿管理器、雲端筆記等）
      • 下次貼上字串並點擊「還原配置」即可恢復所有設定
