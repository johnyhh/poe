Log File Filter

Step 1: Select Filter Mode

Date Range mode filters records by detected dates. Line Numbers mode cuts raw text by line number and should support any text file that can be opened in Notepad.

Select Date Range

Quick Select:

Select by Line Numbers

Enter the line range to extract. Line numbering starts from 1. For example, From Line 10 to Line 50 will extract lines 10 through 50, inclusive.

Note: If To Line is larger than the actual number of lines, the program will simply extract until the end of the file.

Step 2: Select Files

You can select multiple files. Date Range mode supports log/date-based filtering. Line Numbers mode supports text files readable by Notepad.
